# Dữ liệu

Thư mục này không được đưa lên GitHub (xem `.gitignore`). Đặt các file sau vào đây trước khi chạy code:

| File | Mô tả / nguồn |
|---|---|
| `city_noised.jpg / city_denoised.jpg` | Ảnh nhiễu / ảnh chuẩn (giảng viên cung cấp) |
| `cat_blurred.jpg / cat_sharpened.jpg` | Ảnh mờ / ảnh chuẩn (giảng viên cung cấp) |
| `xray_noisy.jpg / xray_filtered.jpg` | Ảnh X-quang nhiễu tuần hoàn / ảnh chuẩn (giảng viên cung cấp) |

Dữ liệu do giảng viên cung cấp có thể khác bản công khai (vd. đã bị xóa bớt giá trị), nên số liệu có thể lệch so với kết quả trong `outputs/`.
