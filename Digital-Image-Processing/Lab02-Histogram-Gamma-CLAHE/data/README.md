# Dữ liệu

Thư mục này không được đưa lên GitHub (xem `.gitignore`). Đặt các file sau vào đây trước khi chạy code:

| File | Mô tả / nguồn |
|---|---|
| `parrot.jpg` | Ảnh gốc cho bài gamma (giảng viên cung cấp) |
| `Contrast_gamma.png` | Ảnh mẫu cần tái tạo (giảng viên cung cấp) |
| `brain.jpg` | Ảnh MRI cho bài histogram (giảng viên cung cấp) |
| `leaf.jpg, flower.jpg` | Chỉ dùng cho phần Luyện tập thêm, ảnh bất kỳ |

Dữ liệu do giảng viên cung cấp có thể khác bản công khai (vd. đã bị xóa bớt giá trị), nên số liệu có thể lệch so với kết quả trong `outputs/`.
