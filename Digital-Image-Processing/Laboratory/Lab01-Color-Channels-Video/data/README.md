# Dữ liệu

Thư mục này không được đưa lên GitHub (xem `.gitignore`). Đặt các file sau vào đây trước khi chạy code:

| File | Mô tả / nguồn |
|---|---|
| `input.mkv` | Video bất kỳ (định dạng OpenCV đọc được) |
| `icon_big.png` | Ảnh nhỏ để chèn, nên là PNG có nền trong suốt |

Dữ liệu do giảng viên cung cấp có thể khác bản công khai (vd. đã bị xóa bớt giá trị), nên số liệu có thể lệch so với kết quả trong `outputs/`.
