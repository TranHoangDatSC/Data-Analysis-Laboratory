# Dữ liệu

Thư mục này không được đưa lên GitHub (xem `.gitignore`). Đặt các file sau vào đây trước khi chạy code:

| File | Mô tả / nguồn |
|---|---|
| `wine-clustering.csv` | Bộ Wine Dataset for Clustering trên Kaggle (13 feature, không có nhãn) |
| `50_Startups.csv` | Giống ML Lab01 (bản có giá trị thiếu) |
| `Dry_Bean_Dataset.xlsx` | [UCI – Dry Bean Dataset](https://archive.ics.uci.edu/dataset/602/dry+bean+dataset) |
| `Reviews_dataset.csv` | 1 000 câu review nhà hàng có nhãn 0/1, cột `sentence`, `label` (tương tự `yelp_labelled` trong [UCI – Sentiment Labelled Sentences](https://archive.ics.uci.edu/dataset/331/sentiment+labelled+sentences)) |

Dữ liệu do giảng viên cung cấp có thể khác bản công khai (vd. đã bị xóa bớt giá trị), nên số liệu có thể lệch so với kết quả trong `outputs/`.
