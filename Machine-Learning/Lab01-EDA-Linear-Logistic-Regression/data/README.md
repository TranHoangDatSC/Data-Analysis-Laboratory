# Dữ liệu

Thư mục này không được đưa lên GitHub (xem `.gitignore`). Đặt các file sau vào đây trước khi chạy code:

| File | Mô tả / nguồn |
|---|---|
| `50_Startups.csv` | Bộ 50 Startups phổ biến trên Kaggle; bản của lớp **đã bị xóa bớt giá trị** (7 ô thiếu) để luyện cleaning |
| `Social_Network_Ads.csv` | Bộ Social Network Ads trên Kaggle; bản của lớp thiếu 17 ô `EstimatedSalary` |

Dữ liệu do giảng viên cung cấp có thể khác bản công khai (vd. đã bị xóa bớt giá trị), nên số liệu có thể lệch so với kết quả trong `outputs/`.
